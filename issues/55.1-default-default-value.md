The **default default value** of an optional parameter is a `None`. These parameters are called **uninitialized** parameters.

When an optional parameter was specified, it was required to be given a default value.
```cpl
func moveForward(steps?: int = 1): void {
%                              ^ default value
	return print(steps);
}
moveForward();  % prints "1"
moveForward(2); % prints "2"
```

Now that requirement is relaxed. If not provided, the default value *defaults* to `None`, and its type is now a `Maybe[T]`, where `T` is the declared parameter type.
```cpl
func moveForward(steps?: int): void {
	steps; %: Maybe[int]
	return print(steps);
}
moveForward();  % prints "None()"
moveForward(2); % prints "Some(2)"
```
As with uninitialized variables (#96), the read type of the uninitialized parameter is `Maybe[T]` while the write type is just `T`.
```cpl
func moveForward2(mut steps?: int): void {
	val steps_1: str        = steps; %> TypeError
	val steps_2: str | null = steps; %> TypeError
	val steps_3: str?       = steps; % ok
	set steps = None[int]();         %> TypeError
	set steps = Some[int](3);        %> TypeError
	set steps = null;                %> TypeError
	set steps = 3;                   % ok
	delete steps;                    % ok
	return;
}
```
But unlike uninitialized variables, uninitialized parameters need not be declared with the `mut` keyword. (As a reminder, parameters without `mut` cannot be reassigned or deleted.)
